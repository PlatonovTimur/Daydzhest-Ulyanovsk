# Дайджест Ульяновск

**Версия: v1.0.0**

> Хроника учебного года — от первого звонка до последнего дня.  
> Не отчёт, не портфолио. Просто память, собранная в одном месте.

---

## 📖 О чём этот сайт

Этот сайт — не про достижения и не про оценки. Он про моменты между ними:
про верёвочный курс, про физику, которая внезапно оказалась интересной,
про бумажных котиков, которых «много не бывает», и про людей, с которыми
всё это происходило.

Каждый месяц здесь — отдельная глава. Внутри — короткий рассказ о том,
что было, и фотографии, которые говорят больше любых слов.
Листайте, вспоминайте, улыбайтесь.

## ✨ Что внутри

- **Главы по месяцам** — от сентября до августа, каждая со своим настроением.
- **Живые фотографии** — галереи с подписями, которые можно открыть на весь экран.
- **Две темы** — светлая для дня, тёмная для вечера. Переключается одним кликом.
- **Ничего лишнего** — только HTML, CSS и немного JavaScript. Быстро, легко, без зависимостей.

## 🎨 Как это сделано

Сайт собран вручную, без конструкторов и фреймворков.  
Стили — на CSS-переменных, чтобы темы переключались плавно.  
Галереи — многоколоночные, как в Pinterest: фото разной высоты, но аккуратный вид.  
Лайтбокс — на чистом JavaScript, без библиотек.

Шрифты — Manrope, Playfair Display и DM Mono.  
Палитра — фиолетовые оттенки: от лавандового до глубокого ночного.
